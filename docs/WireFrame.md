# ShramSamriddhi (The Labor Bridge) - UI Mockup & Wireframe Layout

This document outlines the low-fidelity text wireframe layout for the **Worker-Facing Mobile App Interface**. It is designed with a **Mobile-First, Low-Literacy approach**: heavy reliance on icons, clear numeric balances, large touch targets, and persistent voice-assistance features.

### UX Design Decisions for Screen 1:
* **`[🔊 Change Lang]` Button:** Positioned prominently at the top right so non-English/non-Hindi speakers can change to regional voice-guided interfaces instantly.
* **Wallet Split Layout:** Directly demonstrates to the user how much money they can spend right now vs. how much wealth is safely accumulating in their long-term pension pot.
* **One-Tap Action Target:** The Welfare Radar card gives an explicit, simple call to action (`Tap to Activate`), hiding background API complexities (Aadhaar/DigiLocker verification) behind a single biometric click.

### UX Design Decisions for Screen 2:
* **The Contribution Split:** Visually reinforces the core value proposition to the worker—showing them that by using the app, they got **₹3,800 free extra money** from contractors that they wouldn't have received in an all-cash informal economy.
* **Transparent Ledger:** Demystifies financial transactions by clearly itemizing everyday calculations (Wage vs. Savings vs. Contractor Match) using accessible language.
* **Voice Assistant Anchor:** A large floating microphone row at the bottom allows workers to query their funds via natural language (e.g., *"How much pension do I have now?"*).

### UX Design Decisions for Screen 3:
* **Automatic Regulatory Calculation:** The platform forces the contractor to explicitly acknowledge and commit to the **5% matching welfare allocation** as a baseline transaction requirement to get verified, reliable labor.
* **Tax and ESG Incentives:** Highlighting the **ESG/Labor Welfare Score** and providing a downloadable tax-deduction certificate explicitly satisfies the corporate needs, creating a functional business hook to drive employer adoption.
